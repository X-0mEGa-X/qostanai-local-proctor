# Member 3 support role

The captain and Codex now own all presentation work: the six-slide PDF, three-minute script, pilot proposal and jury answers. The active prompts are in [the captain presentation guide](CAPTAIN_PITCH.md).

Member 3 has no laptop-dependent deliverables. Optional ways to help:

- Join a consented second-face test on the captain's or Member 2's laptop.
- Listen to the pitch and point out unclear explanations.
- Ask practice jury questions from a phone or printed notes.
- Help time the rehearsal or record the demonstration, if available.

No software installation, repository branch or separate AI workflow is required for this role. Required outputs remain with the captain and Member 2.
